# Говори

Бесплатное русскоязычное приложение для альтернативной коммуникации (AAC). Рассчитано на людей, которые не могут говорить и пользоваться руками (например, при БАС), но управляют устройством взглядом. Один файл `index.html`, без сборки и без серверов.

## Возможности

- Крупные плитки готовых фраз, нажатие сразу произносит фразу.
- Крупная русская клавиатура с подсказками слов; приложение запоминает слова, которые вы часто пишете.
- «Помощник»: подсказки фраз по контексту разговора и по набранному тексту.
- Озвучивание русскими голосами iPhone, выбор голоса и скорости.
- Работает офлайн (кроме подсказок помощника), данные хранятся только в браузере.

## Запуск на iPhone

1. Выложите `index.html` на любой статический хостинг, например GitHub Pages (Settings, Pages, ветка `main`).
2. Откройте адрес в Safari, нажмите «Поделиться», «На экран Домой».
3. Управление взглядом: Настройки, Универсальный доступ, Отслеживание взгляда (iPhone 12 и новее, iOS 18+).
4. Качественный русский голос: Настройки, Универсальный доступ, Речь, Голоса, Русский.

## Умные подсказки (необязательно)

Без ключа «Помощник» показывает готовые фразы. Чтобы получать подсказки от ИИ, вставьте ключ Anthropic API в «Настройках». Ключ хранится в `localStorage` вашего браузера, а при запросе подсказок контекст и набранный текст отправляются в Anthropic. Запросы идут напрямую из браузера, поэтому используйте отдельный ключ с лимитом расходов.

## Ограничения и планы

- Клонирование голоса в браузере не подключается. Планируется нативная версия на Swift с Apple Personal Voice (поддержку русского нужно проверить) либо подключение сервиса клонирования.
- Редактирование своих фраз, режим вызова помощи, лучшее предсказание слов, офлайн-кэш (PWA).
- Это не медицинское изделие и не заменяет подбор AAC специалистом.
